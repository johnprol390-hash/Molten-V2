# 🌋 Molten V2

A Pump.fun-style memecoin launchpad for the Hyperliquid ecosystem. Launch tokens, browse the board, watch live charts — **no trading**.

## Features

- **Board** — Real-time grid of token cards with King of the Hill, sort tabs, live ticker, search, infinite scroll
- **New Coins** — Live feed of fresh launches with pause toggle
- **Trending** — Ranked list by trending score with timeframe toggles
- **Token Detail** — Candlestick charts, bonding curve, holders, comments, activity feed
- **Launch** — Create a token in seconds (wallet required)
- **Profiles** — Wallet profiles with coins, comments, follow system
- **Simulated Live Engine** — Realistic price/candle/holder updates via server-side ticks + SSE

## Tech Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- lightweight-charts for candlestick charts
- Prisma + PostgreSQL (Neon/Supabase compatible)
- Zustand + TanStack Query
- Wallet connect via MetaMask/Phantom (SIWE sign-in)

## Local Setup

### Prerequisites

- Node.js 18+
- pnpm
- PostgreSQL database (local, Neon, or Supabase)

### Steps

```bash
# Clone and install
git clone <repo-url>
cd molten-v2
pnpm install

# Configure environment
cp .env.example .env
# Edit .env with your DATABASE_URL

# Set up database
pnpm db:push
pnpm db:seed

# Start dev server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `DATABASE_URL` | Yes | PostgreSQL connection string |

Example:
```
DATABASE_URL="postgresql://user:password@host:5432/molten?schema=public"
```

## Vercel Deployment

1. Push to GitHub (already connected to Vercel at `molten-v2.vercel.app`)
2. In [Vercel Project Settings → Environment Variables](https://vercel.com/johnprol390-4731s-projects/molten-v2/settings/environment-variables), add:
   - `DATABASE_URL` — your Neon or Supabase PostgreSQL connection string (required for Production + Preview)
3. Redeploy from the Vercel dashboard (or push a new commit)
4. Seed the production database once:

```bash
DATABASE_URL="your-production-url" pnpm db:push && pnpm db:seed
```

### Vercel Settings

- **Production URL:** https://molten-v2.vercel.app
- **Framework Preset:** Next.js
- **Install Command:** `pnpm install --no-frozen-lockfile` (set in `vercel.json`)
- **Build Command:** `prisma generate && next build`
- **Node.js Version:** 18.x or 20.x
- **Note:** No cron jobs (Hobby plan). Live sim ticks use client polling + SSE.

### Troubleshooting

If deploy fails with a cron error, ensure `vercel.json` has no `crons` block. Hobby accounts cannot use per-minute crons.

## Simulation Engine

All live data is generated by `src/lib/sim/engine.ts`. The engine:
- Advances prices, bonding progress, and holder counts every tick
- Generates candle data across all timeframes
- Occasionally launches new tokens and graduates existing ones
- Creates ticker events for the live feed

Replace this module with a real Hyperliquid indexer behind the same function signatures when ready.

## No Trading Policy

This platform intentionally has **zero trading UI**. Where Pump.fun shows buy/sell panels, Molten shows token stats and a "Trading coming soon" waitlist panel. Activity feeds display simulated buy/sell history as read-only data.
